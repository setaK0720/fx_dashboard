# MT5連携・バックテスト機能 実装計画

## 目標
MetaTrader 5 (MT5) と連携し、以下の機能を持つシステムを構築します。
1. **自動売買Bot**: MT5を通じて実際に取引を行うPython Bot。
2. **バックテスト機能**: 過去データを使用して戦略を検証し、結果をダッシュボードで可視化する。

## 技術スタック
- **Library**: `MetaTrader5` (MT5操作), `pandas` (データ処理), `backtesting` (バックテスト用ライブラリ)
- **Architecture**:
    - **Bot Process**: FastAPIとは別のプロセスとして稼働し、MT5を制御。DBを介してダッシュボードと連携。
    - **Backend**: バックテスト実行API、Bot制御API。
    - **Frontend**: バックテスト設定・実行画面、結果グラフ表示。

## 実装詳細

### 1. 環境構築
- `MetaTrader5` パッケージのインストール。
- **設定ファイルの読み込み**: `D:\FX\forex_mytools\AccountInfo.json` からMT5のパスと口座情報を読み込む。
    - 対象アカウント: `XM_Micro_BariBali` (デフォルト)
- MT5端末のインストールと設定（アルゴリズム取引の許可）。

### 2. 自動売買Bot (`backend/bot/`)
- **機能**:
    - MT5への接続・ログイン。
    - リアルタイムレート取得。
    - ロジック判定（例: 移動平均線クロス）。
    - 注文送信・決済。
    - 稼働状況とポジションをデータベース (`bot_status`, `positions`) に同期。
- **構成**:
    - `mt5_client.py`: MT5との通信ラッパー。
    - `strategy.py`: 売買ロジック。
    - `trader.py`: メインループ。

### 3. バックテスト機能
- **Backend (`POST /api/backtest`)**:
    - パラメータ（通貨ペア、期間、戦略設定）を受け取る。
    - MT5からヒストリカルデータを取得。
    - `backtesting.py` 等を使用してシミュレーション実行。
    - 結果（損益推移、統計データ）をJSONで返す。
- **Frontend (`BacktestPanel`)**:
    - 設定フォーム（期間、初期資金など）。
    - 実行ボタン。
    - 結果表示（資産推移チャート、勝率、PFなどの指標）。

## ユーザーフロー
1. **Bot稼働**: ダッシュボードから「Start Bot」を押すと、バックグラウンドでBotプロセスが開始。MT5上で取引が行われ、ダッシュボードに反映される。
2. **バックテスト**: ダッシュボードの「Backtest」タブで戦略と期間を選択して実行。数秒〜数分で結果が表示され、戦略の有効性を確認できる。

## 必要な追加ライブラリ
- `MetaTrader5`
- `pandas`
- `backtesting` (または自作シミュレーター)
- `matplotlib` (バックエンドで画像生成する場合) or データのみ返してRechartsで描画
