# 修正内容: ドロップダウンリストの表示修正

## 概要
レートパネルのドロップダウンリストが口座情報パネルの下に隠れてしまう問題を修正しました。

## 変更点
### フロントエンド
- `frontend/src/features/dashboard/RatePanel.tsx`:
  - 親コンテナ (`Box`) に `position="relative"` と `zIndex={10}` を追加しました。
  - これにより、レートパネルが新しいスタッキングコンテキストを作成し、後続の要素（口座情報パネル）よりも手前に表示されるようになります。

## 検証方法
1. ブラウザでダッシュボードを開きます。
2. レートパネル（左上のパネル）の通貨ペア選択ドロップダウンをクリックします。
3. ドロップダウンリストが口座情報パネルの上に正しく表示され、各項目がクリック可能であることを確認してください。
