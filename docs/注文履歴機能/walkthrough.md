# 注文履歴機能・UI改善 ウォークスルー

## 概要
ユーザーが過去の取引履歴を確認できる機能を追加しました。また、ポジション決済時の確認ダイアログを削除し、操作性を向上させました。

## 実施した変更

### 1. 注文履歴機能の実装 (`feature/order-history`)

#### Backend
- **`MT5Client.get_history_deals`**: 指定期間の約定履歴を取得するメソッドを追加。
- **`GET /api/history`**: 履歴データをフロントエンドに提供するAPIエンドポイントを作成。タイムゾーンのズレを考慮し、取得終了日時を「明日」に設定。

#### Frontend
- **`HistoryPanel.tsx`**: 履歴一覧を表示する新しいコンポーネントを作成。
- **`Sidebar.tsx`**: ナビゲーションに「History」を追加。
- **`App.tsx`**: 画面遷移ロジックにHistory画面を追加。
- **`api.ts`**: 履歴取得用の関数 `fetchHistory` を追加。

### 2. ポジション決済のUI改善
- **`PositionTable.tsx`**: 個別ポジションの "Close" ボタン押下時の確認ダイアログ (`confirm`) を削除し、即座に決済されるように変更。

## 検証結果
- **履歴表示**: サイドバーの「History」から、過去30日間の取引履歴が正しく表示されることを確認。
- **当日データ**: `datetime.now() + timedelta(days=1)` の対応により、直近（当日）の注文も漏れなく表示されることを確認。
- **決済動作**: 確認ダイアログなしでスムーズに決済できることを確認。
