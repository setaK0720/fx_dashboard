# バックテストパネル UIレイアウト改善

## ゴール
デスクトップデバイスでの画面スペースをより有効に活用するため、バックテストパネルのレイアウトを改善します。
現在のレイアウトは1カラムであり、ワイドスクリーンでは右側に大きな空白が生じています。
新しいレイアウトでは、デスクトップでは2カラム（設定用サイドバー、結果用メインエリア）とし、モバイルデバイスでは1カラムに戻るレスポンシブデザインを採用します。

## ユーザーレビュー事項
- **レイアウトの選択**: 「サイドバー + メインコンテンツ」の構成で問題ないか？（左：設定、右：チャート/結果）

## 変更案

### フロントエンド
#### [MODIFY] [BacktestPanel.tsx](file:///d:/FX/fx_dashboard/frontend/src/features/backtest/BacktestPanel.tsx)
- メインコンテナを `Grid` または `Flex` に変更します。
- レスポンシブなグリッドテンプレートを定義します：
    - モバイル (`base`): `1fr` (縦積み)
    - デスクトップ (`lg`): `300px 1fr` (サイドバー + メイン)
- **左カラム (サイドバー)**:
    - すべての設定入力（通貨ペア、時間足、戦略、日付、パラメータ、実行ボタン）をここに移動します。
    - 設定項目の `SimpleGrid` を3カラムから1カラムに変更し、サイドバーの幅に合わせます。
- **右カラム (メインコンテンツ)**:
    - すべての結果表示（統計カード、価格チャート、資産曲線、トレード履歴テーブル）をここに移動します。
    - 統計カードの `SimpleGrid` はそのまま維持します（自動レスポンシブ）。
    - チャートは既存の `ResizeObserver` により自動的にリサイズされます。

## 検証計画

### 手動検証
1.  **デスクトップ表示**:
    - ワイドスクリーンでダッシュボードを開きます。
    - 設定が左側、チャートが右側に表示されることを確認します。
    - レイアウトがコンテナの全幅を使用していることを確認します。
2.  **モバイル表示**:
    - ブラウザウィンドウを狭くするか、DevToolsのモバイルエミュレーションを使用します。
    - レイアウトが縦積み（設定が上、チャートが下）になることを確認します。
3.  **機能性**:
    - バックテストを実行し、新しいレイアウトでチャートとテーブルが正しく描画されることを確認します。
