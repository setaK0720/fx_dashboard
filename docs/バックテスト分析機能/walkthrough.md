# バックテスト分析機能 ウォークスルー

## 概要
バックテストの結果を詳細に分析するための機能を追加しました。
資産推移（Equity Curve）だけでなく、実際の価格チャート上での売買ポイントの確認や、トレード履歴の詳細な確認が可能になりました。

## 主な機能

### 1. 価格チャート (Price Chart)
- **機能**: バックテスト期間中の価格変動（ローソク足）を表示します。
- **可視化**:
    - **Buy Entry**: 緑色の上矢印 (▲)
    - **Sell Entry**: 赤色の下矢印 (▼)
    - **Exit**: 反対方向の矢印で決済ポイントを表示
- **目的**: 戦略がどのようなタイミングでエントリー・エグジットしたかを視覚的に検証できます。

### 2. トレード履歴テーブル (Trades Table)
- **機能**: 全トレードの詳細リストを表示します。
- **表示項目**:
    - Entry Time / Exit Time
    - Type (BUY/SELL)
    - Entry Price / Exit Price
    - Profit (損益)
- **スタイル**: ダークテーマに最適化され、視認性を確保しています。

### 3. データ読み込みの改善
- **日付指定**: 分析期間を任意に指定してデータをロードできるようになりました。
- **安定性**: データの読み込み処理を見直し、エラーハンドリングを強化しました。

### 4. レスポンシブレイアウト
- **デスクトップ**: 設定（左）と結果（右）の2カラム表示で画面を有効活用。
- **モバイル**: 縦積みの1カラム表示で操作性を維持。
